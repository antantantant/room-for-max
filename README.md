# Apartment Room for Max

A single-page 3D model of a Tuscan-styled bedroom, built from a pencil sketch with [three.js](https://threejs.org).

Furniture positions are measured off the floor plan in the sketch and scaled by assuming the bed is 2.0 m long, which makes the room about 4.2 m × 2.6 m. The wall with two windows faces east. Colours and materials are a Tuscan interpretation, since the sketch is in pencil.

The window panes are bevelled glass with real transmission, so the landscape outside bends at the bevels.

Open `index.html` through any static server (for example `python3 -m http.server`), then drag to rotate and scroll to zoom. There is no build step; three.js loads from a CDN.
